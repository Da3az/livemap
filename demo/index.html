Headless verification

Captured by npm run spike. The z6.2 view is the explicit regression guard: an earlier prototype sized arrowheads in metres and they ballooned to nearly the radius of the shrunken curves.

Not wired yet: Postgres. The API runs on an in-memory repository behind the same interface, pending migration approval — so anything you draw is lost when the server restarts.

Not wired yet: real auth. AuthResolver is a seam with a fixed demo actor; there is no login.

Known gaps: icons do not de-conflict at low zoom, and labels avoid each other but not geometry.
