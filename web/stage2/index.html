livemap — three visual directions for the editor

The same screen three ways: the editor with a real map, the tools, the feature list and the style panel open on a selected area. The map is a real MapLibre map over OpenFreeMap tiles showing Cyclone Shaheen's approach to Oman (October 2021). Use the LTR / RTL switch above each sample to see it mirrored with an Arabic interface.

Second round: C and B, changed as you asked.
  • C · Atlas now has light and dark. Use the Light / Dark switch above its sample. Dark has its own neutrals, its own state colours and its own eight map colours, which pass the colour-blindness check on every pair.
  • B · Control room has its tools in a dock at the bottom of the map, like C, with a word and shortcut beside each icon. The left rail is gone, so the map is wider.
  • Between the two, I recommend C. It now covers dark as well, its map colours pass in both modes where B's do not, and its light mode matches the light pages maps are published on.
  • A is unchanged, further down, for reference.
